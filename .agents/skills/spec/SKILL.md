# Specify a task

Read and follow the [project's spec workflow](../../../.claude/skills/spec/SKILL.md).
Use the issue number or task description accompanying the skill invocation as `$ARGUMENTS`.
If there is no task description, ask what to specify and wait for the answer.
When you add a new specification, update the document index in `AGENTS.md`.
